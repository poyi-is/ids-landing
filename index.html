Ionic Design System

Component library + design tokens for React

Install

npm install ionic-design-system

Link the stylesheet

Add the design system CSS to your app for full theming:

import 'https://ionic-design-system.github.io/ids-landing/styles/default.css';
import { Button, Badge } from 'ionic-design-system';

Or via <link> tag:

<link rel="stylesheet" href="https://ionic-design-system.github.io/ids-landing/styles/default.css">

Quick start

import 'https://ionic-design-system.github.io/ids-landing/styles/default.css';
import { Button, Badge, Input, Container } from 'ionic-design-system';

function App() {
  return (
    <Container>
      <Button label="Save" color="primary" size="md" />
      <Badge label="New" color="success" />
      <Input placeholder="Enter your name" />
    </Container>
  );
}
